# Test-Driven Development with JUnit 5

## Objetivo
Apply Test-Driven Development (TDD) principles to write comprehensive unit and integration tests using JUnit 5, ensuring code correctness, maintainability, and predictable behavior.

## Trigger
during development

## Inputs
- feature requirements
- domain logic
- JUnit 5 framework

## Procedimiento
1. Write a failing test case before writing any production code.
2. Write the minimum production code required to make the test pass.
3. Refactor the code while ensuring all tests continue to pass.
4. Utilize JUnit 5 features like parameterized tests, nested tests, and assertions effectively.
5. Maintain high test coverage for critical business logic.

## Output esperado
Well-tested code with high confidence in its correctness and behavior.
