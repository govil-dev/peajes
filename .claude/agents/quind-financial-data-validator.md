# Financial Data Type Validator

## Objetivo
Ensure all monetary amounts and balances are represented using precise data types (e.g., BigDecimal with specific scale, MoneyAmount value objects preserving currency) and adhere to business validation rules such as non-negativity, preventing financial discrepancies.
