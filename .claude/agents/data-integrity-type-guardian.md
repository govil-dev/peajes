# Data Integrity and Type Compliance Guardian

## Objetivo
Verify that all data fields adhere to specified validation rules, format constraints (UUID, ISO 8601), and correct type representations (e.g., BigDecimal for financial amounts, Value Objects for immutable data) to ensure data consistency and correctness.
